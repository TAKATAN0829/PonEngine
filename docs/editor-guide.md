# Editorの使い方

Visual Studioで `CG2` をスタートアップにし、DebugまたはDevelopmentで起動する。作業ディレクトリは `project/CG2`。ReleaseはEditorなしでゲームを起動する。

## 画面配置と文字

```text
┌───────────────────────────────────────────────┐
│ Scene / Viewメニュー・再生操作                 │
├──────────┬─────────────────────┬──────────────┤
│Hierarchy │ SceneView / GameView│ Inspector    │
│          │                     │              │
│          │ 描画・選択・移動      │              │
├──────────┴─────────────────────┴──────────────┤
│ Project / Console                             │
└───────────────────────────────────────────────┘
```

タイトルバーをドラッグして配置を変更できる。「表示 / View → 初期レイアウトに戻す」で標準配置へ戻す。配置は `editor-layout.ini` に保存される。

標準表示はHierarchy・Inspector・Project・Console・SceneView・GameViewの6タブ。SceneViewとGameViewは中央で切り替える。再生操作は上部に置き、Toolbarタブは作らない。選択時のタブ背景・上線・タイトルバーの強い色は使わない。

Particle Editor・World Settings・Cameraは「表示 / View」から必要なときだけ開く。各画面は閉じるボタンで閉じられる。初期レイアウトへ戻すと補助画面も閉じる。

既定フォントはWindowsのメイリオ18px。倍率は0.85固定。フォントファイルをリポジトリへコピーする必要はない。

## SceneとGame

- Scene：Editor用カメラで配置を編集する。モデルをクリックして選択し、XYZ軸をドラッグして移動する。
- Game：ゲームカメラとSpriteを含めた表示を確認する。
- Scene画像のサイズ変更に合わせて描画先・投影行列・クリック判定も更新する。
- Scene上の右ドラッグで視点回転、中ボタンドラッグで平行移動、ホイールで前後移動。「注視」ボタンで選択対象へカメラを移す。カメラのキーボード操作は行わない。
- Ctrlを押して移動するとSnapの間隔へ合わせ、Escで移動開始位置へ戻す。
- 描画されないオブジェクトはHierarchyから選択する。

## Particle Editor

「表示 / View → Particle Editor」で補助画面を開く。Particle選択中のInspectorやProjectからも開ける。

1. 「プレビュー開始」でScene内の発生位置へカメラが移動し、連続発生を始める。
2. 「Particleだけを表示」でモデルを隠して確認できる。
3. 発生位置・拡散範囲・一度の発生数・間隔・寿命を調整する。
4. 最小／最大速度・加速度・粒子サイズ・色・画像・合成方法を調整する。
5. 「プリセット書出し」で `resources/particles/Default.ponparticle` へ書き込む。次回起動時にも読み込む。

「一度だけ発生」はBurstとして一回だけ生成し、その後は新しく発生させず寿命まで動かす。一時停止中は「1フレーム進める」を使える。「リセット」で現在の粒子と発生タイマーを初期化する。

設定変更は主に次に生まれる粒子へ反映する。すぐに新しい設定だけで確認したいときはリセットする。実際の管理数も100粒までに制限するため、高頻度・長寿命でも粒子リストは増え続けない。

ゲームの再生中はParticle設定の編集を無効にする。Particleのプレビュー操作は、ゲームの再生・一時停止とは独立している。

## 保存の区別

- 「シーン / Scene → 保存」またはCtrl+S：配置・名前・見た目・Component状態・Emitter設定。
- Particle Editorのプリセット書出し：発生条件・粒子の見た目などのプリセット。
- 終了時に未保存のParticle設定がある場合も保存確認を表示する。
- Particle設定の読込・既定値への変更では、現在の変更を破棄する前に確認する。
- シーン内Emitterは個別にUndo/Redoできる。共通プリセットのUndo/Redoと任意の画像のインポートは未対応。

## ProjectとConsole

Projectのモデルボタンは、Hierarchyで選択中のオブジェクトへ読み込み済みのモデルを適用する。Consoleにはシェーダー・保存・読込などの実ログを表示する。アセットのインポートやログの全履歴検索は今後の機能。

## 開発者向け検証

```powershell
MSBuild tests/SceneFileTests.vcxproj /p:Configuration=Debug /p:Platform=x64 /m:1 /nr:false
./generated/scene-file-tests/bin/SceneFileTests.exe
./tests/RunEditorGraphicsTests.ps1
./tests/RunEditorStartupTests.ps1 -Configuration Debug
```

GraphicsTestsは本番と同じソースを試験用の起動コードでビルドし、実GPUで90フレーム描画する。Scene描画先の連続リサイズ、記述子ハンドルの維持、D3D12検証エラー、パネルのドッキング、日本語字形、Particleの上限・Pause・Burst・Resetを確認する。設定ファイルはgenerated配下のコピーのみを使い、制作中のシーンやプリセットは保存しない。

StartupTestsはソリューション全体を再ビルドし、本番のWinMainからGameSceneを生成して90フレーム動作させる。DevelopmentとReleaseも指定できる。クラスの定義を変えた後、古い中間ファイルや壊れたヘッダー依存記録が残っていると、新旧のクラス配置が混在して起動時にアクセス違反になる場合がある。その場合はデバッグを停止して再ビルドする。コンパイラがC1902などで失敗した後も、依存記録を再生成するため全体を再ビルドしてから確認する。

## オブジェクトの追加

Hierarchyの空白部分を右クリックし、「新規作成」から空オブジェクト、点光源、Particle、Plane、Axisを追加できる。
空オブジェクトにはInspectorからMesh Rendererを付けられる。点光源は位置、色、強度、範囲、減衰を編集できる（最大8個）。
Particleは選択してParticle Editorで編集する（最大32個、各100粒子）。発生位置はTransformと共通で、Emitterの回転・拡縮は未対応。設定はシーン保存・Undo/Redo・停止時の復元に含まれる。
Particle Editorの「プリセット書出し」は選択したEmitterを共通プリセットへ書き出す操作で、シーン保存とは別。
Scene内ではメッシュを持たないオブジェクトにも位置マーカーを表示する。

シーン管理は上部のSceneメニュー、再生操作はToolbar、結果通知は下部へ分離している。
Toolbarの三角は再生、四角は停止、二本線は一時停止、縦棒付き三角は1フレーム更新。
Undo/RedoはCtrl+Z、Ctrl+YまたはCtrl+Shift+Z。新規はCtrl+N、読込はCtrl+O、再生/停止はCtrl+P。
保存形式6は種類別Component・親ID・カメラ設定を含み、従来の形式1〜5も引き続き読み込める。


## Hierarchyの親子関係

オブジェクトを別のオブジェクトへドラッグ＆ドロップすると、その子にできる。右クリックメニューの「親を外す」、またはHierarchyの空白部分へドロップすると親を解除する。親子付け・解除は見た目の位置・回転・拡縮を維持する。

子のInspectorに表示するTransformは親に対するローカル値。SceneViewの移動ギズモと注視ボタンはワールド座標を使う。親を動かすと子のモデル、点光源、Particleの発生位置も追従する。Particleは発生済みの粒子をワールド空間に残す。

親を無効にすると子孫も非表示になる。親の複製・削除は子孫もまとめて対象とし、Ctrl+Zで一回の操作として戻せる。保存・読込・再生停止時の復元にも親子関係を含める。

階層は64段まで。自分自身・子孫への親子付けを拒否する。親の拡縮が0に近い場合や、回転と非均等拡縮の組合せでせん断が必要になる場合は、見た目を保った変更ができないため操作を拒否し、Hierarchyに理由を表示する。


Hierarchyの操作は右クリックメニューにまとめている。オブジェクト上で右クリックすると、その対象を選択して新規作成・複製・削除・親解除・選択解除を表示する。空白部分の右クリックでは新規作成を表示する。新規オブジェクトは最上位へ追加する。空白部分の左クリックでも選択を解除でき、Ctrl+D・Deleteなどのショートカットも使える。


## カメラとProjectブラウザ

Hierarchyの右クリック→新規作成→Cameraでカメラを追加する。最初のカメラは自動でメインになる。InspectorのMain Cameraで切り替え、画角とNear/Far Clipを編集できる。GameViewとReleaseは保存した有効なメインカメラを使い、未指定・無効時は既定の視点を使う。カメラの親子付け、保存、Undo/Redoにも対応する。保存形式6にカメラ設定を追加し、形式1〜5も読み込める。

Projectはresources以下のフォルダとアセットをタイルで表示する。フォルダはダブルクリックで開き、空白の右クリックから上のフォルダ・resourcesへ戻る・更新を選べる。検索は表示中フォルダのファイル名を対象とする。PNG/JPEG/BMPは実画像、対応する3Dモデルは形状を白色で描画したサムネイルを表示する。その他は種類アイコンを表示する。

resources以下のOBJ・glTF・GLB・FBXは右クリックでシーンへの配置や選択中のMesh Rendererへの適用ができる。読み込めないモデルはエラーを表示し、シーンを変更しない。静的メッシュは子ノードの変換を頂点へ反映し、ボーンやアニメーションを持つモデルは階層を保持する。メッシュごとの複数マテリアルに対応する。埋込みテクスチャは白画像へフォールバックする。ParticleプリセットからParticle Editorも開ける。任意のシーンへの切替は未対応。プレビューの新規読み込みは一フレーム一件、タイルのキャッシュは64件、3D描画結果は24件まで保持する。上限以降や読み込めないアセットは種類アイコンを表示する。


## Projectからのドラッグ配置

Projectの対応モデルをSceneViewへドラッグ＆ドロップすると、その位置へ追加して選択する。既存モデルの三角形の表面を優先し（AABBは候補の絞り込みだけに使用）、当たらなければXZ平面、それも使えなければ視線の10単位先に配置する。GameViewは配置対象にしない。

Hierarchyのオブジェクト上へドロップすると、その子として親の位置へ配置する。空白部分なら最上位の原点へ追加する。配置はCtrl+Zで一回の操作として取り消し、Ctrl+Yで復元できる。読み込めないモデルや変換できない親では一覧を変更せず理由を表示する。

## 移動・回転・拡縮ギズモ

SceneViewのツール選択でMove／Rotate／Scaleを切り替える。移動はワールド軸、回転はワールド軸のリング、拡縮はローカル軸をドラッグする。Ctrlで移動・拡縮の距離を指定間隔へ、回転を15度刻みへ揃える。Escで操作前へ戻し、確定後はCtrl+Z／Ctrl+YでUndo／Redoできる。非一様拡縮の親によってせん断が必要になる回転は拒否する。LightとParticleは移動のみ、Cameraは移動と回転を使う。

## マテリアルとテクスチャ

InspectorのMaterialsを開くと、モデル内のスロットごとに色・光沢・ライティングを変更できる。スロットを展開し、ProjectのPNG／JPEG／BMPを「画像をここへドロップ」欄へドラッグすると画像を適用する。欄の右クリックからモデル既定値へ戻す、または白画像へ変更できる。Mesh RendererのColorは全体に乗算する色で、Lightingを外すと全スロットのライティングが無効になる。モデルを変更するとスロットの上書きとアニメーション設定を初期化する。

変更したスロットだけをシーン・Prefabに保存する。他のオブジェクトと同じモデルを使っていても編集値は共有しない。画像が読み込めない場合は既存設定を維持し、理由を表示する。保存形式7に設定を追加し、形式1〜6の読み込みも維持している。

## Prefab

Hierarchyの対象を右クリック→「Prefabとして保存」でファイル名を入力して保存する。子孫とComponentをまとめてresources/prefabsの.ponprefabへ保存する（同名ファイルは上書き）。ルートの位置は原点にし、ワールドの回転・拡縮と子のローカル配置を保持する。せん断を含むルートは保存を拒否する。

ProjectのPrefabをSceneViewまたはHierarchyへドラッグして配置できる。Projectの右クリックからも原点へ配置できる。配置時は全オブジェクトのIDと親の参照を振り直し、Undo／Redoでは一つの操作として扱う。上限超過・不正ファイル・変換できない親ではシーンを変更しない。配置後はルートに元Assetへのリンクを保持する。Hierarchyから保存したルートも保存先へ接続する。ルートを右クリック→PrefabのApplyで子孫ごと元Assetを上書きし、RevertでAssetから子孫を復元できる。他の配置はRevertした時に更新する。RevertではルートのID・親・ローカルTransformを保持し、子のIDは再採番する。シーン上のRevertはUndo可能。Applyによるファイルの変更はUndo対象外。入れ子Prefabや個別Override一覧は未対応。

## ボーンアニメーション

クリップを含むモデルを配置すると、InspectorにAnimationを表示する。Clipで選択し、Preview / Pauseで個別に再生・一時停止する。チェック欄の右クリックから停止して開始位置へ戻せる。Timeでシーク、LoopとSpeedで繰り返し・速度を調整する。Play On Startを有効にするとゲーム再生で自動再生し、全体のPause／Stepにも従う。編集時の個別プレビューは一時状態で、経過時間をUndo履歴や保存へ書き込まない。

位置・拡縮は線形補間、回転はQuaternion補間で評価する。ノード階層とボーンの逆バインド行列・ウェイトからインスタンス専用の頂点をCPUで更新する。停止中は同じ姿勢を再計算しない。選択範囲も変形頂点へ追従する。GPUスキニング、大量キャラクター向けの最適化、モーフ、クリップ間ブレンド、遷移グラフ、ルートモーション、STEP／CUBICSPLINE補間の再現は未対応。


## 複数選択と一括編集

HierarchyまたはSceneViewでCtrl+クリックすると選択を追加・解除できる。最後に選択した対象が主選択となり、ギズモの基準位置になる。Hierarchyの右クリックは既存の複数選択を保持する。Ctrl+DとDelete（または右クリックの複製・削除）は選択した子孫をまとめて処理し、Undoでは一操作として扱う。親子を同時選択しても同じ子を二度複製・移動しない。

移動・回転・拡縮ギズモは選択ルートを一括操作する。回転と拡縮の基準は主選択の位置で、Escは全対象を開始値へ戻す。親の非均等拡縮などでTRSにできない変換は一括で拒否する。
複数選択中のInspectorは主選択の値を表示し、変更した項目だけを反映する。Transformはローカル値の差分を選択ルートへ、Activeと色は選択全体へ適用する。種類固有のComponentは単体選択で編集する。

## パフォーマンスの確認

上部の「表示 / View」→「Performance / パフォーマンス」で開く。通常の6タブには追加せず、閉じていても直近600フレームを固定長バッファへ記録する。

- FPS、フレーム時間、DrawCall数、UI描画コマンド数、送信三角形数、延べインスタンス数を確認できる。DrawCallはMeshが実際に発行した命令を集計し、モデル・Sprite・Particle・Assetプレビューを含む。三角形数はインスタンス数を含む送信量で、画面上の可視ピクセル数ではない。
- CPU内訳はEditor、履歴、Project／Console、Hierarchy、Inspector、SceneView、モデル／テクスチャ読込、シーン更新、モデル更新、CPUアニメーション、Particle、Assetプレビュー、描画命令記録を表示する。子区間は親の時間に含むため、全行を足し合わせない。
- Present／VSync、GPU完了待ち、60fps制限の待機を別々に表示する。待機時間が長いだけでGPU負荷とは断定しない。GPU executionには同じフレームのGPUタイムスタンプ差分を表示する。PreDrawからPresent直前の描画命令までのGPU上の経過時間で、Scene・UI・プレビュー・フレーム内転送を含む。Present／VSyncやFPS制限のCPU待機は含まない。未対応・取得失敗はN/Aと表示する。CPU時間と足し合わせない。
- グラフをクリックすると履歴だけを一時停止し、そのフレームの内訳を調べられる。ゲームは継続する。「最も重かったフレーム」は600フレームより前でもリセットまで保持する。CSV出力は現在の履歴を作業ディレクトリのperformance-capture.csvへ保存する。

Models／CPU animationが伸びたらモデル数・頂点数・再生数、Particlesが伸びたら発生数、Project／読込が伸びたら新規Assetやプレビュー、DrawCallが増えたらオブジェクト・マテリアルスロット・Emitter数を確認する。これは絞り込みの手掛かりで、原因の自動断定は行わない。

保存形式8でPrefabの元Assetパスを追加した。形式1〜7も読み込める。

GPU executionは履歴・ピーク記録・CSVにも保存する。CSVのgpu_validが0の場合、gpu_msは空欄とし、未取得を0msと区別する。GPU時間が増えた場合は三角形数・DrawCall・画面解像度等を比較し、CPU時間が増えた場合はCPU区間の内訳を確認する。GPU内の描画別内訳や使用率はまだ計測していない。


## 回転・往復移動Component

1. Hierarchyで対象を単体選択し、Inspectorの空白を右クリックする。
2. 「Componentを追加」からRotation（自動回転）またはPing Pong（往復移動）を選ぶ。両方を同時に付けられる。
3. Rotationは各ローカルEuler角の速度を度/秒で指定する。Ping Pongは開始位置からの変位と一往復の秒数を指定する。変位は親の座標系で、半周期で終点、全周期で開始位置へ戻る。両端では滑らかに折り返す。
4. 再生すると動き、Pauseで停止、Stepで一更新だけ進む。停止すると再生前のTransformとComponent設定へ戻る。再度再生すると時計も最初から始まる。

各ComponentのEnabledで一時的に止め、見出しの右クリックから削除できる。Activeが無効な対象とその子は動かず、往復移動の時計も進まない。往復移動は最初に有効になったゲーム更新時の位置を開始点とする。

設定はシーン・Prefab・複製・Undo/Redoで保持する。実行中の開始位置と時計は保存しない。保存形式9で追加し、形式1〜8は動作Componentなしで読み込む。エンジンの既存の固定更新に合わせ、一更新は1/60秒として進行する。往復移動中の位置はComponentが更新するため、他の位置操作との重ね合わせは未対応。PerformanceのCPU内訳「Motion components」で更新負荷を確認できる。


## Box / Sphere Collider

対象を単体選択してInspectorの空白を右クリックし、「Componentを追加」からBox ColliderまたはSphere Colliderを選ぶ。一つのオブジェクトに一つのColliderを付け、Shapeで種類を切り替える。Center、Boxの全幅Size、SphereのRadiusはTransformに対するローカル値として指定する。見出しの右クリックで削除、Enabledで一時的に無効化できる。

SceneViewでは選択中のColliderだけを表示する。通常は緑、直前のゲーム更新で接触中なら赤、無効なColliderや階層なら灰色。GameViewには補助線を表示しない。Boxは親子の回転・拡縮・せん断を含む形状で判定し、AABBは候補を絞るためだけに使う。Sphereは非均等拡縮時に最大拡縮の球、せん断時に安全側の外接球とする。表示と判定には同じワールド形状を使う。Boxの拡縮が0に近い場合など、形状が退化する場合は判定対象から外す。

再生中、Consoleの[Collision Enter]に接触開始、[Collision Exit]に終了をIDと名前で表示する。接触中は毎フレーム通知しない。Pauseでは判定結果を維持し、Stepで一更新、Stopで履歴を初期化する。Activeが無効な親の子、Enabledが無効なColliderは判定せず、次のゲーム更新で接触終了になる。

押し戻し・重力・摩擦・反発はRigidbodyで設定する。レイヤーフィルタと高速移動の連続判定は未対応。同じ有効なRigidbodyに属する子Collider同士は判定しない。最大256個（無効なものを含む）とし、同時通知は一更新32件まで表示して残り件数をまとめる。PerformanceのCPU内訳「Collision detection」で判定と通知の負荷を確認できる。

Collider設定は保存形式10、Prefab、複製、Undo/Redoに含まれる。形式1〜9はColliderなしで読み込む。接触履歴は保存しない。


## Rigidbody・重力・押し戻し

床・壁にはColliderを付ける。自身にも親にも有効なRigidbodyがなければ固定物となる。落下させる物体にはColliderとRigidbodyを付け、ModeをDynamic、Use Gravityを有効にして再生する。RigidbodyもInspectorの空白の右クリック→Componentを追加から選び、見出しの右クリックで削除できる。

- Static: 重力や接触で動かない。床の摩擦・反発を調整したい場合に付ける。
- Dynamic: 重力・初速・衝突で並進移動する。質量に応じて押し戻しを分配する。往復移動Componentからの位置更新は無視する。
- Kinematic: Transformや往復移動Componentで動かす床・壁に使う。重力では動かず、接触相手のDynamicを押せる。

Gravity ScaleでワールドY方向の重力-9.8を調整し、Initial Velocityはワールド単位/秒の初速を再生開始時に適用する。Massは正の質量、Restitutionは反発、Frictionは接触時の摩擦、Linear Dampingは速度の減衰を指定する。物理速度は最大1000単位/秒に制限する。低速の接地では反発を抑え、静止時の細かな跳ねを減らす。

ColliderのTriggerを有効にすると、開始・終了通知だけを行って押し戻しを省略する。重力はそのまま適用する。Rigidbodyを持たない子Colliderは最も近い有効な親Rigidbodyの一部として動き、同じRigidbody内では衝突しない。

Pauseでは位置と速度を維持し、Stepで一更新進める。停止すると編集前のTransform・設定へ戻り、速度と接触履歴を破棄する。設定は保存形式11、Prefab、Undo/Redoに含む。形式1〜10はRigidbodyなし・Trigger無効で読み込む。PerformanceのPhysics / gravity / responseで更新負荷を確認する。

並進物理の基盤で、角速度・トルク・回転への衝撃・ジョイント・スリープ・連続衝突判定は未対応。Dynamicは動かない親の下に置く。Dynamicの子階層へ別の有効なRigidbodyを置く構成と、Kinematicの下にDynamicを置く構成は再生・保存前に拒否する。子Colliderを複数使う場合は親だけにRigidbodyを付ける。固定1/60秒の更新を4分割して解決するが、速い物体や薄い床ではすり抜ける可能性がある。

再生中に不正なRigidbody設定や未対応の親子構成へ変更すると、物理更新だけを止めてConsoleの[Physics]に理由を出す。設定を直すと再開する。

## Editorの画面とプロパティ編集

Unityに近い落ち着いたグレー、細いツールバー、角の少ない入力欄に統一した。フォント倍率は0.85固定。通常表示はHierarchy / Inspector / Project / Console / SceneView / GameViewの6タブで、追加ツールは「表示 / View」から開く。新しい初期配置では左がHierarchy、中央がSceneViewとGameView、右がInspector、下がProjectとConsoleになる。配置は引き続きドッキングで調整できる。

Inspectorは左に項目名、右に入力欄を揃える。TransformのPosition / Rotation / Scaleは各3軸を一行に表示し、Rotationは度数で編集する。保存とエンジン内部の回転単位は従来どおりラジアン。見出しの「?」に説明をまとめ、TransformのリセットとComponentの削除は見出しの右クリック、追加はInspectorの空白の右クリックから行う。

SceneViewの「View / 表示」メニューからGrid、Snap、選択対象へフォーカスを操作する。Projectは左のフォルダツリーと右のAssetプレビューに分かれ、境界をドラッグして幅を調整できる。画像やモデルのドラッグ＆ドロップは従来どおり利用できる。

Consoleは検索でログを絞り込める。一覧には各ログの先頭行を表示し、ホバーで全文を確認、右クリックで全文をコピーできる。画面最下部には操作結果とFPS・フレーム時間・GPU時間を表示する。
